# FlashTrans

Windows 下的划词翻译和截图工具。

## 能干什么

- 划词翻译：选中文字后按 `Ctrl+Alt+Q`，或让程序在选中后直接弹译文。
- 多源翻译：默认开谷歌、微软、有道、腾讯交互翻译；也可以自己加官方 API 和 AI 源。
- 文件翻译：支持 EPUB、TXT、Markdown、DOCX 和文本层 PDF；支持加密断点续译、用户术语表，以及独立双语 HTML 阅读副本。
- 截图：按 `F1` 框选区域，能标注、复制、保存、钉住、识别文字、识别后翻译。
- 长截图和录制：支持长截图，也能录成 WebP / GIF / MP4。
- 结果显示：可开多列对比、双语对照、多个目标语言；单词会显示词典结果。
- 外观：深浅色主题、字号、字体、透明度、紧凑模式，窗口位置会记住。

## 快速开始

解压后运行 `FlashTrans.exe`。默认只开免费源，不用填 Key。

自编译需要 .NET 9 SDK：

```powershell
tools\publish.cmd fast   # 自包含包
tools\publish.cmd small  # 依赖 .NET 9 Desktop Runtime
```

发布会**原位覆盖已有目录**，不随版本升级换路径。本工作区沿用 `dist\FlashTrans-1.9.0-win-x64-fast/` 和 `dist\FlashTrans-1.9.0-win-x64-small/`；目录中的历史版本字样不再代表程序版本，当前程序为 **1.9.1**。全新工作区没有产物时创建固定的 `dist\FlashTrans-win-x64-fast/` 和 `dist\FlashTrans-win-x64-small/`。`fast` 自带运行时，`small` 需要 .NET 9 Desktop Runtime。

发布先在临时目录完成构建和校验，再正常关闭目标目录内的程序实例；仍不退出时结束该实例并等待释放占用，然后覆盖程序文件。不会结束其他目录中的程序，也不会清空原目录的 `portable.txt`、`data/`、日志或额外用户文件。构建失败不覆盖；覆盖中失败会尝试回滚。多个同类型发布目录并存时会要求先明确目标，不擅自挑选或新增目录。

压缩执行 `powershell -NoProfile -File tools\pack-release.ps1 -Version 1.9.1`，包在 `dist\release\`，同版本重复打包会替换同名包。包名标记新版本，**包内顶层目录沿用原目录名**，解压升级不会另建程序目录。打包只收录本次构建清单中的程序文件并校验 SHA256，跳过原目录保留的便携配置、日志及额外文件。

发布脚本回归：先构建当前 Release 主工程，再运行 `powershell -NoProfile -File tests\FlashTrans.SelfTest\ReleaseScriptsProbe.ps1`。在临时工作区模拟构建产物，真实验证进程占用解除、原位覆盖、便携数据保留、同名 ZIP 替换和构建哈希检查，不改动实际发布目录。

### 剪贴板保护与应用排除

「设置 → 通用 → 划词翻译」中的“翻译后还原剪贴板”默认开启。借用剪贴板前会备份文本、HTML/RTF、图片、文件列表及可复制的自定义格式；遇到无法完整复制的私有格式、占用或过大的数据时跳过取词并提示，不降级为只保留纯文本。恢复前在系统剪贴板锁内核对序列号，不覆盖期间新复制的内容。取消取词仍会完成已经发出的复制请求的保护收尾。

“排除应用”填进程名，用分号分隔，例如 `KeePass.exe; notepad.exe`。不区分大小写、精确匹配，不接受通配符。被排除应用的自动划词、划词快捷键和双击 Ctrl 不取词；剪贴板自动翻译同时检查前台和剪贴板来源应用。不影响手动输入、显式翻译剪贴板和截图。

## 翻译源

默认启用 4 个免费源：谷歌、微软、有道、腾讯交互翻译。

可选源分三类：

- 免费 / 自建：LibreTranslate、MyMemory、Lingva、DeepLX。
- 官方 API：DeepL、Azure、Google Cloud、百度、腾讯、彩云小译。
- AI：OpenAI 兼容接口、Gemini、Claude。

费用和额度按各家官方文档为准。设置里可以测试、复制、排序和切换默认源。

**添加 AI 源**：在「设置 → 翻译源 → 添加源」最上方选择「AI 翻译（OpenAI 兼容）」，填写接口地址和 API Key，再点击模型旁的 **拉取模型**，从下拉列表选择或直接手填模型 ID。请求携带当前 Key；本地无鉴权服务可留空。仅填写域名时使用 `/v1/models`，填写 `/v1`、自定义网关路径或完整 `/chat/completions` 地址时保留对应 API 前缀。权限不足、不支持列表或返回为空都会提示，且不会清空已填写模型；列表中可能含非聊天模型，请选可用于文本翻译的模型。切换地址或 Key 后需重新拉取。AI 源徽标使用名称首个完整字符（英文字母大写），设置卡片与结果卡片保持一致。

翻译源与截图状态可定向回归：先构建当前自测工程，再运行 `dotnet .\tests\FlashTrans.SelfTest\bin\Release\net9.0-windows10.0.19041.0\FlashTrans.SelfTest.dll --only-source-capture`。使用本机 HTTP 测试服务和隔离配置，覆盖模型鉴权、权限/超时/取消、深浅主题编辑、名称徽标、菜单顺序，以及真实截图蒙层内的弹窗保留；加 `--shot` 可输出设置界面预览到 `shots/`。

## 文件翻译

在主窗口右上角、双语对照左侧点击 **文件翻译**，将文件拖进大框（也可点击选择），选好翻译源和语言后点击 **开始翻译**。一次处理一个文件、一个目标语言。默认生成与原件扩展名一致的译文副本；勾选“输出双语对照 HTML”则生成独立的 `.html` 阅读副本。

- **输出位置**：默认保存到源文件目录；可选择其他文件夹，并勾选「设为默认输出位置」。取消默认则恢复源目录，右侧重置图标可仅为本次选择源目录。默认路径不存在时会提示重选，不静默改存其他位置。
- **目标语言**：文件翻译独立记住上次选择，关闭窗口或重启后仍保留，不改变主窗口的目标语言；首次使用沿用主窗口语言。
- **文件名**：`原文件名_译文_zh-CN.ext`，重名时增加 `(2)` 等编号，不覆盖原件或已有译文。
- **翻译历史**：右侧显示最近 100 条任务，可打开译文、打开目录、重新载入原件。记录成功、失败和取消状态；只存路径、语言、源名称、时间及进度，不存正文或密钥。清空历史不删除文件。
- **保存失败**：已完成译文保留在当前窗口，换输出目录后点击「重试保存」，不重复翻译。未保存前请不要关闭窗口。

| 格式 | 处理方式与边界 |
| --- | --- |
| TXT | 保留换行、空行和段首/段尾空白。识别带 BOM 的 UTF-8/16/32；无 BOM 优先严格 UTF-8，失败时尝试 GB18030（兼容 GBK）并提示。编码识别有歧义时请先转成 UTF-8。输出统一 UTF-8。 |
| Markdown（`.md`、`.markdown`） | 按语法树翻译标题、段落、列表和表格正文。代码、公式、链接地址、图片及替代文字、HTML 块、YAML 元数据、链接 title 和引用式链接标签保留。为避免目录断链，被文件内部链接引用的标题也保留原文并提示。输出统一 UTF-8。 |
| DOCX | 翻译正文、表格、页眉页脚、脚注尾注、批注和 Word 文本框，保留文档结构及媒体资源。图片文字、公式、图表/SmartArt、嵌入对象及删除修订不翻译。译文长度可能改变分页，自动域更新可能覆盖字段结果；不承诺像素级版式一致。不支持旧版 `.doc`、加密或带数字签名的文档。 |
| EPUB | 处理标准 XHTML 章节、导航目录、书名/简介/主题，保留阅读顺序、链接、CSS、图片和字体，并更新书籍及章节语言。代码、公式、SVG/图片文字、属性文字和 `translate="no"` 区域不翻译。不支持 DRM、多个内容版本或无法安全解析的非标准 XHTML；允许保留标准字体混淆。 |
| PDF | 仅本机提取文本层，生成 A4 正文重排版 PDF，不保留原图片、表格、公式、交互表单或版式。多栏阅读顺序需要人工核对。加密文件、扫描件和含无文本页的混合文件明确拒绝，不静默漏页；上限 500 页。输出嵌入可用系统字体的子集，无合适字形或涉及暂不支持的复杂文字排版时提示改选双语 HTML。 |

### 断点续译、用户术语和双语输出

- **跨重启续译**：勾选“保存续译进度（本机加密）”，再开始翻译。重新打开程序后载入原件，使用相同翻译源、语向、分批大小和术语表，点击开始即可自动恢复已完成段落。源语言及所选服务会独立记住。进度按段保存，取消或退出不必从头请求。
- **隐私与清理**：保存进度默认关闭。开启后，包含已译正文的进度保存在配置目录的 `document-checkpoints/`，使用当前 Windows 账户的 DPAPI 加密；不能直接搬到另一台电脑或另一账户恢复。加密/落盘失败会明确报错，不回退到明文。点击“清除本机进度”删除已存进度，不删除原文件、译文、术语或历史；当前窗口的内存结果保留。
- **失效与损坏**：原文件内容、翻译源配置、语向、分批大小或术语变化会创建新进度，不能把旧译文混入。意外退出导致末条写入不完整时，只恢复完整记录并提示重新翻译末段；中间记录损坏或无法解密时停止，需清理后重译。每份进度上限 64 MB，完成后仍保留，用户可自行清理。
- **术语表**：支持 UTF-8 TSV/CSV 两列 `source`、`target`，也支持 TBX 2/3。使用“新建 / 编辑”在本地维护；TBX/CSV 编辑后另存 TSV，不覆盖原词库。原词最长 200 字、译词最长 500 字；上限 10 万条/64 MB。英文忽略大小写并按单词边界匹配，长词优先；不跨翻译分段或行内格式片段匹配，也不自动变形。普通 TSV/CSV 同词冲突直接拒绝；TBX 多义冲突词跳过并显示数量，导入后可在本地补充明确译法。
- **公开术语资料**：文件窗口的“公开术语资料”打开 Microsoft 官方术语页面。按资料方的授权下载 TBX 后可导入；导入时必须指定源语言，会按目标语言筛选，简繁中文分开处理。程序不后台抓取、不预置授权不明的整库，也不会为查询术语上传正文。
- **术语保护**：命中的术语以独立标记发送，返回后按用户指定译法还原。缺少或重复标记会阻止输出并提示换源，推荐使用能遵循指令的 AI 源；免费网页接口不保证保留标记。不会通过整段译文的全局替换误改合法字符。
- **双语 HTML**：生成 `原文件名_双语_目标语言.html`，逐段排列可翻译原文与译文，可在浏览器阅读或打印。该副本不保留原文件的图片、代码、公式、表格版式和其他未进入翻译的内容，不替代原件。文本转义并禁止脚本/外部资源，无联网阅读依赖；长段落随翻译分批切分。关闭此选项即可继续输出原格式译文，切换输出模式不需要重译。

### 翻译源与隐私

- 文件只在本机解析；点击开始后，**可翻译文字会发往选中的服务**。本任务不走多源聚合、不自动切源，也不写入划词翻译缓存。文件任务元信息另存于配置目录的 `document-history.json`，目录设置存于 `settings.json`；便携模式仍使用 exe 同目录的 `data/`。
- Ollama / LM Studio：在「设置 → 翻译源」添加「AI 翻译（OpenAI 兼容）」，选本地预设，填写实际模型名；先在外部启动服务并加载模型，再到文件窗口刷新翻译源。本机地址不等于离线保证，需要确认服务未转发云端模型。
- 含行内样式的段落会带保护标记。**推荐使用能遵循指令的 AI 源**；缺少、重复或乱序的标记会导致任务停止，不会把损坏译文写回文件。免费网页翻译接口未必能保留这些标记。
- 长文按“每批字符数”串行分段，默认 600 字符，可在 200–2000 调整；请求间隔默认 200 毫秒，可在 0–5000 调整；单段超时默认 180 秒，可在 10–600 调整。文件任务固定单并发，同一源最多重试两次，避免接口限流；不复用划词翻译的自动语言反转设置。
- 取消/失败后可在**当前窗口**继续已完成进度；开启加密进度后支持跨重启恢复，未开启则关闭窗口后丢失内存进度。支持用户术语表，尚不提供全书语义上下文或自动摘要记忆。
- 只有全部段落成功才自动输出。先写输出目录内的临时文件，再以新文件名完成保存；失败和取消会清理临时文件。单文件上限 64 MB、解压内容 128 MB、正文 200 万字符/2 万段。

## 截图和 OCR

- `F1` 框选，`Esc` 取消，回车执行默认动作。
- 在翻译结果窗口按截图快捷键时保留窗口，可直接截取译文；完成或取消截图均不自动收起窗口，原先手动收起的窗口也不会被展开。
- 工具条里有标注、长截图、录制、识别、钉住、保存、复制。
- 钉住后可以把截图贴在屏幕上；鼠标移到贴图上能复制、保存或销毁。滚轮缩放，`Ctrl+滚轮` 调透明度（最低 20%）；右键或“⋯”菜单恢复 100% 原图尺寸、选择透明度、启用鼠标穿透。穿透后按住 `Ctrl+Alt` 即可恢复交互，不需要先点到贴图。缩放和透明度只影响查看，复制/保存仍使用原始像素。
- 截图按屏幕物理像素裁切，PNG 无损保存；普通钉住按原图像素显示，无原选区的长图按比例缩小到可见范围，不拉伸变形或放大小图。
- OCR 用本机 RapidOCR 或 Windows OCR，不上传截图。小字、花底色、竖排可能识别不准，重要内容要人工核对。
- 识别文字和识别后翻译会先显示窗口，识别完成后原地填入结果；识别中可关闭或收起，旧结果不会重新弹窗或覆盖下一次翻译。
- 程序启动后的空闲阶段会预加载翻译弹窗和本地 OCR 引擎，减少首次调用的初始化等待；识别耗时仍取决于截图大小和所选引擎。

## 数据

- 正常模式：配置在 `%AppData%\FlashTrans`。
- 便携模式：exe 旁边放一个空的 `portable.txt`，配置写到 `data\`。
- API Key 用 Windows DPAPI 加密后保存。
- 可选文件续译进度也使用 DPAPI 加密，单独保存在 `document-checkpoints/`；自选术语表仍是用户管理的本地文件。

### 本轮新增回归

先构建当前自测工程，再运行 `--only-protection` 验证剪贴板多格式/图片/取消/竞争保护、应用排除及贴图原生窗口行为；运行 `--only-documents` 验证文件翻译，包括真正的独立进程断点续译、术语、双语导出和 PDF。常规测试只使用临时文件、本机 HTTP 测试服务及隔离配置。PDF 输出需可用系统字体，复杂扫描件和复杂脚本文字排版不在当前能力范围内。
