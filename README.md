# FlashTrans

Windows 划词翻译 + 截图工具。原生 WPF，不依赖任何第三方库，启动约 0.4 秒，常驻内存约 72 MB。

聚合 17 种翻译源（免费接口 + 官方 API + AI 大模型），出错自动降级到下一个可用源。

## 功能

- **划词翻译**：选中文本后出现小图标，点一下就译；也可设为选中即译
- **聚合多源**：免费源开箱可用，无需配置；官方 API 与 AI 源填密钥即可。某个源报错就自动切下一个
- **标签页换源**：结果区顶部标签直接切源，`Ctrl+Tab` 轮换，`Ctrl+1..9` 直选
- **截图**：框选屏幕任意区域，标注后保存、复制，或识别文字（本机识别，不联网）。内容比屏幕高就用长截图，滚着接
- **多语言同译**：一次翻成多个目标语言，结果并排
- **双语对照**：原文与译文逐段对照
- **词典**：单词自动显示音标与释义，一键跳转欧路词典
- 深色/浅色主题、强调色、字号、透明度、紧凑模式；窗口可自由缩放并记住位置

## 快速开始

下载后直接运行 `FlashTrans.exe`。免费源已默认启用，选中任意文本按 `Ctrl+Alt+Q` 即可。

自己编译（需要 .NET 9 SDK）：

```
tools\publish.cmd fast     # 自包含单文件，什么都不用装（推荐）
tools\publish.cmd small    # 依赖已安装的 .NET 9 Desktop Runtime，体积最小
```

产物在 `dist\`。打包前先退出正在运行的实例（托盘右键最后一项）。

`fast` 包免安装，但**整个文件夹要一起拷**——单文件发布不会把 WPF 的原生 DLL 塞进 exe，只拿 exe 走会启动失败。两个包都要保留同目录下的 `Assets\app.ico`，托盘图标从它加载。

## 截图

按 `Ctrl+Alt+A`（或托盘右键 → 截图），屏幕定格，拖一个矩形框住要截的地方。松手之后八个把手可以拖着改大小，选区下面浮出工具条。`Esc` 或右键取消。

框选时按 `空格` 直接框住鼠标底下那个窗口，`Ctrl+A` 框住整个桌面。

### 工具条

工具条分两行。第一行是画东西的工具、颜色、撤销重做和收尾动作，第二行是当前工具的参数。

| 工具 | 键 | |
| --- | --- | --- |
| 矩形 | `R` | |
| 圆 | `O` | |
| 箭头 | `A` | |
| 画笔 | `P` | 随手画 |
| 马赛克 | `M` | 逐块求平均，是实心色块不是模糊，底下的字认不回来 |
| 文字 | `T` | 点一下开始打字。字带一圈反差描边，落在什么底色上都看得清 |

**参数那一行**跟着手上的工具换：

| 选中的工具 | 第二行给的是 | 范围 |
| --- | --- | --- |
| 矩形、圆、箭头、画笔 | 粗细 | 1–24 px，预设 1/2/3/5/8/12 |
| 文字 | 字号 + `B` 加粗 + `I` 斜体 | 8–120 px，预设 14/18/24/32/48 |
| 马赛克 | 格子大小 | 4–64 px，预设 8/12/20/32 |

三种调法：`−` `+` 一格一格挪、点预设直接跳、`Ctrl+滚轮` 连着滚。加粗斜体还有 `Ctrl+B` / `Ctrl+I`，正在打字时也管用。字号跟粗细是分开的两个值，细箭头配一行大字不用先把线调粗。

`Ctrl+Z` 撤销、`Ctrl+Y` 重做（`Ctrl+Shift+Z` 也管用）。重做会把那一笔放回它原来的层。

**按住 `Shift`**：矩形和马赛克出正方形、圆出正圆、箭头吸到 15° 的整数倍、画笔变成拉直线（工具条上没有单独的直线工具，画下划线就用它）。

### 画完还能改

退出画笔工具（再点一下那个按钮，或者按 `Esc`），画上去的东西就都能动了：

- 鼠标移到某一笔上，拖着走就是挪位置。选中的那一笔套一圈黑白虚线框
- **改形状**：点中之后它身上出来几个圆点，拖着改。矩形、圆、马赛克是八个点（四角加四条边的中点），箭头是两头两个点。画笔和文字没有——文字的大小归字号管
- 方向键微调一个像素，按住 `Shift` 走十个
- `Delete` 删掉选中那一笔
- 换颜色、改粗细、改字号、加粗斜体都套在选中那一笔上，画完才想换不用撤销重画

空心的形状（矩形、圆、箭头、画笔）只有线附近能抓，中间抓不住——不然一个占了大半选区的方框会把「拖动选区」堵死。马赛克和文字整块都能抓。

### 收尾动作

| 动作 | 键 | |
| --- | --- | --- |
| 长截图 | `Ctrl+L` | 往下滚着接着截 |
| 识别文字 | `Ctrl+D` | 认出来的字装在一个能改的框里，改完再复制或翻译 |
| 识别并翻译 | `Ctrl+Shift+D` | 认完直接翻 |
| 保存 | `Ctrl+S` | 存成 PNG |
| 复制 | `Ctrl+C` | 进剪贴板 |

`回车` 走哪个动作可以在设置里挑，默认是复制；双击选区也走这个动作。存盘和复制都不经过识别，没装语言包也照样能用。

### 长截图

先框住那块可滚动的区域，按 `Ctrl+L`，程序替你往下滚，一边滚一边把新露出来的部分接到底下，滚到底自己停。中途按 `Esc` 停下，已接好的部分照样留着。接完出来一个预览窗口，在那儿再决定保存、复制还是识别。

接缝靠比对像素找齐，所以滚动条走多少、有没有惯性、页面有没有粘顶的表头都不影响结果。上限 40000 像素高或 200 帧。

### 识别文字

用的是 Windows 自带的 `Windows.Media.Ocr`，**不联网、不上传、不要密钥**，截的内容不出本机。

**前提**：系统里得装对应语言的识别包。Windows 10/11 在「设置 → 时间和语言 → 语言 → 选中一个语言 → 选项 → 可选功能」里勾「光学字符识别」。中文简体通常已装好。一个都没装时设置里会说明去哪装，其余功能不受影响。

识别难免有错字，小字号、花底色、艺术字都会掉准确率，框紧一点会准得多。所以识别结果不直接进剪贴板，而是摆在一个能改的框里，`Ctrl+C` 复制、`Ctrl+Enter` 拿去翻译。

## 设置与数据

配置文件：`%AppData%\FlashTrans\settings.json`
日志：`%AppData%\FlashTrans\flashtrans.log`

**便携模式**：在 exe 同目录放一个 `portable.txt`，配置与日志改存到 `.\data`，不写注册表、不碰 `%AppData%`。

**API 密钥**用 Windows DPAPI 加密后再落盘，只有当前 Windows 用户能解出来。换机器或换用户需要重新填写。

翻译结果有内存缓存，重复查询直接命中。保留时长默认 12 小时，可在「设置 → 通用 → 缓存与网络」里改。

**开机自启**：「设置 → 通用 → 开机启动」写入 `HKCU\...\Run`，带 `--tray` 静默启动到托盘。

## 自测

```
dotnet build tests\FlashTrans.SelfTest -c Release
tests\FlashTrans.SelfTest\bin\Release\net9.0-windows10.0.19041.0\FlashTrans.SelfTest.exe
```

在真实 WPF 环境里把每个窗口、每个设置页都构造一遍，另外覆盖缓存淘汰、抓屏与 OCR、标注的命中与改形状、长截图的位移计算。不带参数 71 项，`--net` 加上联网的共 79 项。

其他参数：`--net` 测各源连通性，`--timing` 打出聚合时每个源的耗时，`--shot` 把各窗口和截图工具条渲成 PNG 写到 `shots\`（样式改动只能看图，断言看不出好不好看），`--benchmark` 测启动耗时。

## 技术栈

WPF / .NET 9 / C#，约 1 万行。Win32 交互（全局热键、低级鼠标键盘钩子、剪贴板轮询、托盘图标、多显示器 DPI、GDI 抓屏）走 `Interop` 目录下的 P/Invoke。

**依赖**：没有任何第三方库。唯一的非框架引用是微软自己的 Windows SDK 投影，靠目标框架 `net9.0-windows10.0.19041.0` 隐式带进来，只为调用系统的 `Windows.Media.Ocr`。
